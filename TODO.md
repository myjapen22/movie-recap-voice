# Movie Recap Voice — TODO

- [x] **Interactive bilingual Android app UI.** The app is named “Movie Recap Voice”; it uses a dark cinematic background with blue and purple gradients and responsive phone-sized layouts. Home provides Movie Narrator and KikiVoice AI. Movie Narrator has a large transcript/subtitle input and optional YouTube, RedNote, or Telegram reference field. The KikiVoice screen opens `https://kikivoice.ai/` in the browser and warns that the external service has separate terms/pricing. History and Settings are interactive screens. English and Burmese are supported; navigation and actions are real app controls, not a static image.

- [x] **Text-only transcript transformations and offline preview.** Users can paste subtitles or a transcript and choose Detailed retelling, Summarize, or Rewrite in English or Burmese. Detailed output is prompted to preserve chronological order and source facts. Copy, Edit, Export TXT, and local History are available. An extractive Offline sample preview works without any Gemini key or API request and is clearly labeled as a non-AI format preview. No audio generation replaces the former audio action.

- [ ] **Permitted transcript/subtitle retrieval from video URLs.** Users may enter supported YouTube, RedNote/Xiaohongshu, or Telegram URLs as references. The prototype validates supported domains but does not download video or automatically retrieve subtitles/transcripts; users must paste text manually. Automatic import remains open until a permitted official access path is available for each platform.

- [x] **Free-only Gemini BYOK and safe failure handling.** Use only the currently verified `gemini-3.8-flash` text model. Users can add/manage up to 10 keys in Android SecureStore; each key has its own SecureStore item, Settings masks the value, and one key is selected manually—adding or removing a key never silently selects/rotates to another. The API call happens directly from Android only after an explicit user tap; there is no custom Gemini server endpoint/setup or server-side key. No paid-model fallback, automatic billing activation, automatic key rotation, or automatic request retry is included. Each key requires the user to confirm it belongs to a Google AI Studio Free-tier project with billing not linked; the app cannot independently verify an account’s billing status. A conservative 3-request Pacific-day cap and 30-second cooldown apply per device. A request marker is persisted before network I/O, so a request interrupted before completion fails closed until the next Pacific midnight rather than being retried automatically. After any HTTP 429, all Gemini requests on that device pause until the next Pacific midnight and a clear Burmese/English message explains the pause. HTTP 5xx and network failures have localized messages. Users can still paste a transcript and generate the offline sample when they have no usable key/quota. Tests mock all network calls; no live Gemini request or real key was used.

- [x] **On-device history and export.** Retellings can be reopened, edited, removed, and cleared with a confirmation; text history and language preference stay on-device. Copy uses the clipboard. TXT export uses the share sheet or Android folder picker, with a browser-download route for Preview.

- [x] **No audio and no paid deployment.** No TTS, audio generation, playback, transcription model, or audio model is included. The KikiVoice entry is only an external browser link, not an in-app voice/API integration. No paid API was called, no billing was enabled, and the app was not published or deployed.
